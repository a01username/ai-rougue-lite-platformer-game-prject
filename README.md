# Ascent

A pixel-art roguelite platformer built with HTML, CSS, and JavaScript.

## Play

Download or clone this repository, then open `outputs/index.html` in a browser. No local server or installation is required.

The game includes eight floors across four mountain biomes, procedural rooms, branching item/shop routes, eight bosses, and selectable controls. The in-game controls panel explains movement and attacks.

Game source and detailed development notes are in `outputs/`.
